Artefact 6: Purpose - Local Chatbot with Ollama
For this week’s portfolio artefact, you will use AI to help you build a simple chatbot in Python and reflect on the development process.

Instructions
Implement a simple command-line chatbot written in Python. The chatbot must use a local model served by Ollama (doesn't matter which model you use, it can be very small), allow the user to enter messages in a loop, display model responses, and provide a clear way to exit the program. Your code should also handle basic errors in communication with the Ollama service.  It should include comments that help explain code structure, but are not excessive.

Your portfolio artefact for this week should consist of a Markdown file containing two parts: one Python code block with the implementation of the chatbot, and the second part with regular text containing a README for your chatbot.

Your README should explain what is needed to run the script (library versions), how to launch it, and how it works. It should also include a section with a reflection written in your own words (100 - 200 words) about your experience with using AI for this task. You may wish to discuss:

How AI helped you understand the code.
How you used AI to generate, explain, debug, or improve code.
How you verified AI-generated suggestions.
What limitations or mistakes you observed in AI responses.
What you learned from working with AI during the activity.
Before Using AI
Before using any AI tools, revise lecture materials from Week 6. Think about your solution's architecture and decide which libraries you will use.
