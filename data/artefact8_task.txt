Artefact 8: Purpose – AI-Powered Word Chain Game
For this week’s portfolio artefact, you will use AI to help you build a simple word chain game in Python and reflect on the development process.

Instructions
Implement a command-line word chain game written in Python. The game must use the IFB220 Azure AI API to drive the AI opponent. The game should follow these rules:

When the program starts, the chatbot greets the user and clearly explains the rules of the game.
The user enters a single noun in English.
The chatbot responds with a single noun that begins with the last letter of the user’s word.
The user then continues the game by entering another single noun that begins with the last letter of the chatbot’s previous word, and the cycle repeats.
If the user enters more than one word, repeats a word that was previously used (by the user or the chatbot), or enters something that is not an English noun, the chatbot should clearly communicate that the user has lost and encourage them to start the game again.
The same rules apply to the chatbot – if it violates any of them, it should acknowledge this and declare the user the winner.
The chatbot must not engage in any conversation or respond to anything unrelated to the game.
A user should be able to end the game using a simple command (e.g., '\bye').
Your code should handle basic errors in communication with the AI endpoints, and include comments that help explain the code structure without being excessive.

Your portfolio artefact for this week should consist of a Markdown file containing two parts: one Python code block with the implementation of the game, and the second part with regular text containing a README for your game.

Your README should explain what is needed to run the script (library versions and how to configure the API key), how to launch it, and how it works. It should also include a section with a reflection written in your own words (100 – 200 words) about your experience with using AI for this task. You may wish to discuss:

How AI helped you understand or design the solution.
How you used AI to generate, explain, debug, or improve code.
How you designed and refined the system prompt, and what techniques you applied.
How you verified AI-generated suggestions.
What limitations or mistakes you observed in AI responses.
What you learned from working with AI during the activity.
Before Using AI
Before using any AI tools, revise the lecture materials from Week 8 on prompt and context engineering. Think carefully about how to design your system prompt: what rules to include, how to phrase them, and how the format of the AI’s responses will affect the flow of the game.
